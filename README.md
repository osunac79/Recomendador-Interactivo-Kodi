# Recomendador-Interactivo-Kodi
Addon de Kodi para los amantes del cine con muchas películas en el disco duro. Ayuda a elegir película mediante un cuestionario de 4 preguntas, dando como resultado 5 películas aleatorias según las respuestas del cuestionario.
